# lampa-plugins
my_bookmarks_sort

Как работает:
Кнопка с тремя полосками появляется в шапке только на страницах закладок. Выбор режима: по дате добавления, по алфавиту, по дате выхода.
Режим хранится по ключу «тип вкладки + фильтр фильмы/сериалы», поэтому каждая вкладка помнит своё.
Сортировка включается только пока открыта страница закладок этой вкладки, так что главная страница и другие части Lampa не затрагиваются.
